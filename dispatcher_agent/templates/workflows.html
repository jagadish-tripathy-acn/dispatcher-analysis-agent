Hung workflow instances

Hung
Still sitting in an EPM task with no state change for more than 48 hours, and not completed or aborted. The threshold is a definition, not a measurement — change it and the count changes.
Age
Time from the last recorded state change to the as-of timestamp above. It is not the total workflow duration.
Completed / Aborted
Reached a terminal state in the window. Aborted covers operator cancellation and template-level abort, which are not distinguished in the source.
In progress
Active and moving — a state change within the last 48 hours. Healthy, not hung.
